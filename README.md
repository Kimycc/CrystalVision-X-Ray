# CrystalVision X-Ray

A unique X-Ray resource pack for **Minecraft 1.21.11**. Instead of plain
flat colors, every ore appears as a glowing 3D **crystal star** floating
inside a neon frame, so you can spot it instantly through the terrain.

## Features
- 3D crystal star model for every ore
- Neon frame that matches each ore's color
- Full-bright glow, easy to see in dark caves
- Stone, dirt, and other filler blocks are made invisible
- Supports: Coal, Iron, Copper, Gold, Diamond, Emerald, Lapis,
  Redstone, Nether Quartz, Nether Gold, Ancient Debris

## Installation
1. Download `XRay_1_21_11_Crystal.zip` from the **Releases** page.
2. Do not unzip it.
3. Open Minecraft, go to **Options > Resource Packs > Open Pack Folder**.
4. Put the zip file into that folder.
5. Activate the pack and enjoy!

## Notes
- Made for Minecraft Java Edition 1.21.11.
- Many multiplayer servers ban X-Ray packs. Use only in singleplayer
  or on servers that allow it, at your own risk.
